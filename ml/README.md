## 1. Purpose

This ML component is a simple academic prototype that predicts a student's
**Placement Readiness Score** (0–100) based on their academic profile and
extracurricular achievements.

It demonstrates a basic end-to-end ML pipeline:

```
CSV Dataset → Feature Engineering → Model Training → Evaluation → Serialised Model → Prediction
```

---

## 2. Features Used

| # | Feature | Description | Typical Range |
|---|---------|-------------|---------------|
| 1 | `cgpa` | Cumulative Grade Point Average | 0 – 10 |
| 2 | `backlogs` | Number of active/history backlogs | 0 – N (integer) |
| 3 | `coding` | Coding assessment score | 0 – 100 |
| 4 | `sql` | SQL / DBMS assessment score | 0 – 100 |

| 6 | `communication` | Communication skill score | 0 – 100 |

| 8 | `certifications` | Number of certifications earned | 0 – N (integer) |

## 3. Target Variable

| Variable | Description | Range |
|----------|-------------|-------|
| `placement_readiness` | Predicted placement readiness score | 0 – 100 |

Higher scores indicate greater readiness for campus/off-campus placements.

---

## 4. Why Decision Tree?

A **DecisionTreeRegressor** was chosen because:

- ✅ Simple and interpretable — easy to explain to non-ML stakeholders
- ✅ Requires no feature scaling/normalisation
- ✅ Trains and predicts fast, even on small datasets
- ✅ Works well for academic prototypes with limited data
- ✅ Can be visualised as a tree diagram for presentations
- ✅ Part of scikit-learn, a standard academic ML library

`max_depth=5` is used to prevent overfitting on the small synthetic dataset.

## 8. Train the Model

```bash
python train_model.py
```

This will:
1. Load `data/sample_placement_data.csv`
2. Validate all required columns
3. Split into 80% training / 20% testing
4. Train a `DecisionTreeRegressor` (max_depth=5, random_state=42)
5. Print MAE and R² evaluation metrics
6. Save the trained model to `models/placement_model.joblib`

**Expected output (approximate):**

```
=============================================
  AI Career Mentor — ML Training Script
  PROTOTYPE · SYNTHETIC DATA
=============================================

[INFO]  Dataset loaded successfully  →  100 rows, 10 columns
[INFO]  Training samples : 80
[INFO]  Testing  samples : 20

=============================================
  Model Evaluation (Test Set)
=============================================
  Mean Absolute Error (MAE) : ~1.50
  R² Score                  : ~0.99
=============================================

[NOTE]  These metrics are based on SYNTHETIC data.
        They do NOT reflect real-world placement prediction accuracy.

[INFO]  Trained model saved to: .../ml/models/placement_model.joblib
[DONE]  Run predict.py to test a sample prediction.
```

> ⚠️ The very high R² score (~0.99) is expected and is an artifact of synthetic
> data being generated with deterministic rules. Real-world data will produce
> lower and more meaningful scores.

## 11. Dataset Disclaimer

> ⚠️ **IMPORTANT — SYNTHETIC / SAMPLE DATA ONLY**
>
> `data/sample_placement_data.csv` contains **100 rows of artificially generated
> data**. It was created solely to demonstrate the ML training pipeline.
>
> - Values were designed to follow plausible ranges and logical correlations.
> - This data **does NOT represent real student placement outcomes**.
> - Model performance metrics on this data are **not meaningful** for real-world evaluation.
>
> **You MUST replace this file with a real, validated placement dataset before
> drawing any conclusions about model accuracy or using predictions for
> actual placement decisions.**

---

## 12. Real-World Usage Note

To use this module with real data:

1. Replace `data/sample_placement_data.csv` with your actual dataset containing
   the same column names.
2. Verify data quality (no missing values, valid ranges, no duplicates).
3. Re-run `python train_model.py` to train a new model on real data.
4. Evaluate the real metrics — expect lower R² scores than with synthetic data.
5. Consider feature engineering and model selection (Random Forest, XGBoost, etc.)
   for production-grade accuracy.
